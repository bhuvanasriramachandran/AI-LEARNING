# AI Learning Companion

An **intelligent, gamified learning platform** designed for **students, parents, and teachers**, with a strong emphasis on **inclusive education for students with learning difficulties** (dyslexia, dysgraphia, ADHD, etc.).

The platform combines **AI-driven personalization, gamified engagement, and assistive technologies** to create an **accessible, adaptive, and engaging learning experience**.

---

```markdown
## Main Theme
```

The **AI Learning Companion** addresses the challenges faced by students with learning difficulties by providing:

* **Dyslexia-friendly interface**: Readable fonts, adjustable spacing, contrast settings
* **Voice-first interaction**: Full text-to-speech and speech-to-text navigation and reading
* **Multi-sensory learning**: Gamification, visual aids, and interactive storytelling
* **Adaptive pacing**: AI adjusts content difficulty and delivery speed according to student progress
* **Progress insights**: Simple, visual feedback for students; detailed analytics for parents and teachers

**Mission:** Reduce frustration, build confidence, and foster independence for students while providing parents and teachers with actionable insights.

```markdown
## Features
```

### For Students

* Gamified learning modules (Unity, Phaser.js)
* Voice navigation and text-to-speech assistance
* AI-powered personalized learning recommendations
* Multi-language support (Tamil, Hindi, Telugu, English)
* Progress tracking, performance badges, and achievements

### For Parents

* Dashboard for monitoring student progress
* Weekly and monthly performance reports
* Notifications for milestones and learning outcomes

### For Teachers

* Class-wide analytics and insights
* Student-specific performance tracking
* Easy content upload and management

```markdown
## Getting Started
```

1. **Clone the Repository**

   ```bash
   git clone https://github.com/Aswini1008/AI-Learning-Companion.git
   cd AI-Learning-Companion
   ```

2. **Frontend Setup**

   ```bash
   cd frontend
   npm install
   npm start
   ```

3. **Backend Setup**

   ```bash
   cd backend
   pip install -r requirements.txt
   python manage.py migrate
   python manage.py runserver
   ```

4. **Access Application**

   * Frontend → [http://localhost:3000](http://localhost:3000)
   * Backend API → [http://localhost:8000](http://localhost:8000)
